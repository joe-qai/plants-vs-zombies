# 🌱 植物大战僵尸 H5 版

一款基于 HTML5 Canvas 开发的植物大战僵尸网页游戏，专为移动端横屏体验优化。

## 🎮 游戏特性

### 核心玩法
- **5行9列** 的经典游戏棋盘
- **10波挑战**，难度逐渐递增
- **6种植物**：向日葵、豌豆射手、坚果墙、毁灭菇、樱桃炸弹、玉米加农炮
- **僵尸系统**：普通僵尸 + BOSS僵尸
- **阳光经济**：收集阳光种植植物

### 游戏机制
- **准备时间**：每波开始前3秒准备期
- **难度递增**：僵尸数量、血量、速度逐波提升
- **BOSS机制**：每波中间位置出现BOSS僵尸
- **胜利条件**：成功抵御10波僵尸进攻

### 视觉效果
- 精美的倒计时Toast弹窗
- 阳光飞行动画效果
- 爆炸粒子效果
- 平滑的UI过渡动画

### 音效系统
- 阳光收集音效
- 植物种植音效
- 爆炸音效
- 僵尸死亡音效
- 游戏胜负音效

## 🚀 快速开始

### 本地运行

```bash
# 克隆项目
git clone https://github.com/joe-qai/plants-vs-zombies.git

# 进入项目目录
cd plants-vs-zombies

# 使用任意HTTP服务器运行
# 方法1: Python
python -m http.server 8000

# 方法2: Node.js
npx serve .

# 方法3: 直接用浏览器打开 index.html
```

### 游戏操作

1. **开始游戏**：点击"开始游戏"按钮
2. **选择植物**：点击下方植物卡片选择
3. **种植植物**：点击棋盘格子种植
4. **收集阳光**：点击阳光收集
5. **游戏目标**：抵御10波僵尸进攻

## 🛠️ 技术栈
